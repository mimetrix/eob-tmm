BIG-IP Next for Kubernetes · Traffic Management Microkernel

A programmable data plane — safe, and live

Customers can shape BIG-IP traffic today with iRules, or wait on a software release. This adds a third path: live surfaces — small, provably-safe programs attached to a running data plane at runtime, reaching internal state iRules can't, applied and removed on live traffic with no restart, and written once to run on any build. One general engine hosts a family of surfaces (observe, diagnose, protect); it is the same class of technology that made the Linux kernel programmable (eBPF), brought inside TMM.

Proven live in the lab: a program attached to an internal traffic function on a running BIG-IP Next, read internal state on real requests, and was removed — no restart, no traffic impact.

The gap today

Two options, and a hole between them.

  • iRules are powerful but bounded — a fixed menu of events and a curated set of data. They can't attach to internal functions, can't see internal state, and can't be changed on a running system without reconfiguration.
  • A code change is fully general and safe, but it's a build-test-release cycle — weeks to a fix, and a restart to deploy it.
  • Nothing today lets an operator safely observe or adjust a running data plane's internals, on live traffic, without disruption.

What it is

A safe extension surface embedded in TMM.

  • A small execution engine inside the data plane that runs tiny programs loaded at runtime. No rebuild, no restart to add or remove one.
  • Every program is proven safe before it runs — mathematically checked that it cannot crash the data plane, cannot loop forever, and cannot read memory it shouldn't. Unsafe programs are refused, not run.
  • Write once, run on any build. A program names the data it needs; the system adapts it to each TMM version automatically at load time.

What it unlocks — the live-surface family

One engine, four kinds of live surface: probe and trace (observe), debug (diagnose), shield (protect).

See & trace · probe / trace

Live visibility into internal traffic state no tool exposes today — effectively a dynamic tracer for the data plane, streaming what's happening inside TMM on real traffic.

Diagnose live · debug

Attach to any function on a running system, read any internal field, detach — with no restart and no traffic disruption. Faster root-cause on production issues than anything available now.

Protect fast · shield

Apply a targeted mitigation — for example, a CVE workaround — to a running fleet in minutes, without waiting on a full patch and release cycle.

Why it matters to the product

  • Time-to-mitigation. Ship a targeted fix to a live fleet in minutes instead of a release cycle — a concrete advantage for CVE response and incident handling.
  • Differentiated observability. A live, in-the-data-plane tracer that neither iRules nor competitors offer — a new answer to "what is BIG-IP actually doing right now?"
  • Platform extensibility. A safe, general surface for new traffic features and customer-specific logic without a TMM release for each one.
